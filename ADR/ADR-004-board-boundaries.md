# ADR-004: 左右は反射し、ターゲット奥側と投射側は盤外とする

- 状態: Superseded
- 決定日: 2026-08-23
- 置換先: [ADR-014](./ADR-014-use-out-of-bounds-on-all-edges.md)

## コンテキスト

Issueでは左右だけ反射する方式と、盤面全体を反射させる方式が併記されていた。全方向を壁にすると、強すぎる投射が盤面へ戻り、カーリングらしい盤外のリスクがなくなる。また、ストーンが長時間動き続ける可能性がある。

## 決定

- 左右の壁では反射する
- ターゲット奥側または投射側からストーン全体が出た場合は盤外とし、0点にする
- 盤面、反発係数、盤外条件の具体値は[`game-specification.md`](../docs/game-specification.md)を正本とする

## 影響

- 衝突などで左右へ向かったストーンは、壁で反射して盤面内へ戻る
- 強すぎる投射は奥へ抜けて0点になり、弱すぎる投射や後方へ弾かれたストーンも0点になり得る
- 全方向を壁にする方式より、盤上のストーンが停止するまでの時間を抑えやすい
