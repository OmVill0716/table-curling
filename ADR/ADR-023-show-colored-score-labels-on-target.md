# ADR-023: ターゲットに得点色付きの固定配点を表示する

- 状態: Accepted
- 決定日: 2026-08-23
- 置換対象: [ADR-018](./ADR-018-show-score-numbers-only-in-result.md)

## コンテキスト

ADR-018では、得点が5投目まで変化し得ることから、Game Screenの得点数値をすべて非表示とした。しかし、ターゲットの各リングが何点かもResultまで表示しない場合、プレイヤーは色と配点の対応を事前に覚える必要がある。

ターゲットへ固定配点を表示しても、各ストーンの現在得点や合計得点を確定表示することにはならない。配点の数字自体を対応色で描けば、ターゲット、ストーン色、得点の関係を盤面上で理解できる。また、数字が色以外の情報になるため、配点を色だけで伝えずに済む。

## 決定

- ターゲットの100点、50点、30点、10点の各領域へ固定配点の数字を常時表示する
- `100`は赤`#D32F2F`、`50`はオレンジ`#F57C00`、`30`は黄`#FBC02D`、`10`は青`#1976D2`で描画する
- `100`は中心、`50`、`30`、`10`はそれぞれのリング上側の領域内へ配置する
- 数字にはSurfaceやリング色の上でも読める高コントラストの輪郭または背景を付ける
- ターゲット外の0点領域には固定の`0`を表示しない
- プレイ中のストーンは現在位置の得点区分に対応する色へ動的に変えるが、ストーン上へ得点数値を表示しない
- Game Screenと`review`では各ストーンの現在得点、暫定合計、得点変化ポップアップを表示しない
- 5投目の停止時に最終得点を一度だけ確定するが、同投目の`review`では各ストーンの確定得点と合計得点を表示しない
- 「結果を見る」の押下後、Resultで各ストーンの確定得点と合計得点を初めて表示する
- 遊び方画面で、ターゲットの数字が固定配点であり、ストーンの色が現在位置の得点帯へ対応することを説明する
- 中心座標による採点、境界線上を内側の高得点へ含める規則、色の動的導出はADR-018から維持する

## 影響

- 初回プレイでも盤面を見ればリングの配点を理解できる
- 配点は数字と色の両方で示され、色だけに依存しない
- 固定配点と未確定のストーン得点を区別する必要がある
- ターゲットの数字がストーンに一時的に隠れる場合を許容する
- Rendererはリング、固定配点、ストーンの順序を考慮して描画する必要がある
- Resultまで伏せる対象は、ターゲットのルール表示ではなく、各ストーンの確定得点と合計得点になる
