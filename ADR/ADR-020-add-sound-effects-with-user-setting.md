# ADR-020: 効果音とON/OFF設定をMVPへ追加する

- 状態: Accepted
- 決定日: 2026-08-23

## コンテキスト

投射、衝突、停止、コースアウトは画面上の変化だけでも判別できるが、効果音を加えるとブラウザゲームとして操作結果を把握しやすくなる。一方、BGMや端末の振動まで扱うと、素材、再生制御、ブラウザ・端末差への対応範囲が広がる。

また、ブラウザはユーザー操作前の音声再生を制限する場合がある。音声を再生できない環境でもゲーム進行を妨げない設計が必要である。

## 決定

- MVPでは投射、ストーン同士の衝突、全ストーンの停止、コースアウトに効果音を付ける
- BGMは実装しない
- 振動は実装しない
- TOPに効果音のON/OFF設定を表示する
- ADR-019の「3つの入口」は主要な画面遷移の入口を指し、効果音設定は画面遷移を伴わない追加設定として扱う
- 初期値はONとする
- ユーザー操作が行われるまでは効果音を再生しない
- 設定は`localStorage`の`table-curling.sound-enabled.v1`へBooleanとして保存する
- 保存値がない場合、不正な場合、または`localStorage`が利用できない場合はONとして扱い、ゲームは継続する
- OFFでは音声リソースの再生を開始しない。再生中の音がある場合は停止する
- 音声再生の失敗はゲーム進行、Physics、採点へ影響させない
- 効果音素材は自作、Public Domain、または利用条件を確認した素材だけを使用する

## 影響

- TOPには3つの主要な入口に加えて効果音設定が表示される
- ゲームイベントから音声再生を分離するAudio Adapterが必要になる
- 衝突が連続した場合でも不快な多重再生にならないよう、実装時に再生頻度と音量を調整する必要がある
- 永続化対象にハイスコアとは独立したユーザー設定が1つ増える
- 効果音をOFFにしても視覚情報だけでゲームを完了できる必要がある
