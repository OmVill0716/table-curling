# ADR-018: プレイ中は得点色だけを変え数値はResultで表示する

- 状態: Superseded
- 決定日: 2026-08-23
- 置換対象: [ADR-005](./ADR-005-score-by-stone-center.md)
- 置換先: [ADR-023](./ADR-023-show-colored-score-labels-on-target.md)

## コンテキスト

後続ストーンとの衝突によって、停止済みストーンの位置と最終得点は5投目まで変化し得る。1〜4投目に得点数値や暫定合計を表示すると、得点が確定したように見える。一方、ストーンを現在位置の得点リングと同じ色へ動的に変える表示は、動きとして面白く、中心座標による判定結果を視覚的に確認できる。

## 決定

- 各ストーンの中心とターゲット中心の距離で得点リングを判定する
- 境界線上は内側の高い得点に含める
- プレイ中はRendererが現在位置の得点区分を導出し、ストーンを対応する得点リングと共通の色へ動的に変える
- Game Screenでは、個別得点、暫定合計、得点変化ポップアップ、色と得点数値の凡例を表示しない
- 1〜4投目の`review`では盤面、ストーン、投数、操作ボタンだけを表示する
- 5投目の停止時に最終得点を一度だけ確定するが、同投目の`review`では数値を表示しない
- 「結果を見る」の押下後、Resultで初めて各ストーンの得点と合計得点を数値表示する
- プレイ中の色はRendererが導出し、Zustandへ毎フレーム保存しない
- リング半径と色の対応は[`game-specification.md`](../docs/game-specification.md)を正本とする

## 影響

- 後続ストーンで位置が変わる可能性を残したまま、最終結果まで数値を伏せられる
- ストーン色の変化によって、どの得点区分に入っているかを視覚的に確認できる
- プレイ中の色は最終得点を保証しない
- Resultでは色に依存せず、各ストーンの得点と合計をHTMLテキストとして確認できる
