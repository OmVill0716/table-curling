# ADR-009: URL Routingを使わず状態で画面を切り替える

- 状態: Superseded
- 決定日: 2026-08-23
- 置換先: [ADR-017](./ADR-017-use-top-and-retire-flow.md)

## コンテキスト

MVPにはStage Select、Game、Resultの3画面がある。各画面をURLとして公開する方法と、ブラウザゲームのように1つのアプリ内状態で切り替える方法がある。

今回は画面ごとの共有URL、ブックマーク、ブラウザの戻る・進む操作を要件としない。ゲーム途中のURLへ直接アクセスできるようにすると、Matter.js Runtimeや投数などの復元方法も別途必要になる。

## 決定

- React Routerは導入しない
- Zustandの`phase`を正本としてStage Select、Game、Resultを切り替える
- 公開URLはアプリのルートのみとする
- ブラウザの戻る・進む操作にはゲーム内画面遷移を連動させない
- 画面遷移はMUIのボタンとゲーム進行イベントから実行する

## 影響

- ブラウザゲームとして1つの画面内で完結する
- URL Routingとゲーム状態復元を実装せずに済む
- Result画面などへの直接リンクやブックマークはできない
- 将来、画面ごとのURLが必要になった場合は、ゲーム状態の復元方針とあわせて置換ADRを作成する
