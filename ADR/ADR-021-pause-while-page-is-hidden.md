# ADR-021: ページ非表示中はゲームを自動停止する

- 状態: Accepted
- 決定日: 2026-08-23

## コンテキスト

モバイルブラウザでは、ゲーム途中に別アプリへ切り替えたり画面をロックしたりして、ページが一時的に非表示になることがある。非表示中の実時間をPowerやPhysicsへ加算すると、復帰時に意図しないPowerで投射されたり、ストーンが瞬間的に移動したりする。

一方、一時的な非表示だけでゲームを破棄すると、ブラウザゲームとして中断に弱くなる。再読み込みやタブを閉じた場合の途中保存を行わない既存方針は維持しつつ、ページが残っている間の一時停止を定義する必要がある。

## 決定

- Game Screenでページが非表示になった時点でゲームを自動停止する
- `moving`ではPhysics更新を停止し、Stoneの位置と速度を維持する
- `charging`では投射せずPower計測をキャンセルし、`ready`へ戻す
- `ready`と`review`は状態を維持する
- 非表示だった実時間をPower、Physics accumulator、停止判定の継続時間へ加算しない
- ページが再表示されたら追加の「再開」操作を要求せず、自動的に処理を再開する
- `moving`の再開時は非表示前と同じ位置・速度からPhysics更新を続ける
- 非表示中に発生したPointer Upやキー解放を投射として扱わない
- 一時停止状態は永続化しない。再読み込み、タブを閉じる、またはブラウザがページを破棄した場合は従来どおり未完了ゲームを失い、次回はTOPから開始する
- `visibilitychange`と`document.visibilityState`をページ表示状態の正本とし、フォーカス喪失は従来どおり`charging`のキャンセルにも使用する

## 影響

- Physics Runtimeは非表示時にAnimation Frameを停止し、再表示時に基準時刻とaccumulatorを初期化してから再開する必要がある
- 一時停止と再開でZustandのGamePhaseを別の値へ変更する必要はない
- `charging`だけは安全のため`ready`へ遷移する
- 固定タイムステップのframe delta上限は、visibilityイベントを取得できなかった場合などの防御として引き続き必要である
- OSやブラウザによってページ自体が破棄された場合の復元は保証しない
