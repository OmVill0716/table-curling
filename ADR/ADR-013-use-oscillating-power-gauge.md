# ADR-013: Powerを最小値と最大値の間で往復させる

- 状態: Accepted
- 決定日: 2026-08-23
- 置換対象: [ADR-003](./ADR-003-use-round-hold-shot-button.md)

## コンテキスト

Powerが0から100まで増加して100で停止する方式では、弱い投射を行うには押下直後の短い時間でボタンを離す必要がある。特にタッチ操作では低いPowerを意図して選びにくい。

長押し、連打、目押しなど、入力自体へゲーム性を持たせる既存ゲームの考え方を参考にしつつ、このゲーム独自のUIとして実装する。

## 決定

- Canvas外の円形投射ボタン、Pointer Events、Space / Enter操作を維持する
- ボタンを押している間、Powerを最小値と最大値の間で連続して往復させる
- 上昇と下降には同じ時間を使う
- Powerは各区間で直線的に変化する
- ボタンを離した瞬間のPowerで投射する
- 投射方向は各投射位置からターゲット中心への固定方向を維持する
- `pointercancel`やフォーカス喪失時は投射せず、Power表示を未操作状態へ戻す
- Powerの範囲と周期は[`screen-flow-and-input.md`](../docs/specifications/screen-flow-and-input.md)を正本とする

## 影響

- 上昇中に狙ったPowerを逃しても、下降中や次の往復で再び狙える
- 弱い投射を選ぶ機会が各往復で得られる
- プレイヤーがゲージを見て離す目押しのゲーム性が加わる
- 押下時間だけからPowerを一意に推測できないため、現在値と増減方向を視覚的に表示する必要がある
- 入力遅延やフレームレートに依存しないよう、描画回数ではなく経過時間からPowerを計算する必要がある
