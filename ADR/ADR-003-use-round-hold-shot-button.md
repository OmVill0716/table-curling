# ADR-003: 円形の投射ボタンを長押ししてPowerを決める

- 状態: Superseded
- 決定日: 2026-08-23
- 置換先: [ADR-013](./ADR-013-use-oscillating-power-gauge.md)

## コンテキスト

Issueには長押し方式と往復ゲージ方式の選択肢がある。モバイルを主対象としつつPCにも対応するため、タッチとマウスで異なるUIを実装せず、同じ操作部品を利用したい。

## 決定

Canvasの外に円形の投射ボタンを配置する。タッチとマウスはPointer Eventsで共通化し、ボタンの押下開始でPowerの充電を始め、離した時点で投射する。

カーリング方式として、投射方向は各投射位置からターゲット中心へ向かう方向に固定する。MVPではプレイヤーによる角度変更を提供しない。

Powerは0から100まで単調増加させ、100で停止して往復させない。充電時間、初速度の範囲、キャンセル動作は[`game-specification.md`](../docs/game-specification.md)を正本とする。

ボタンはHTMLの`button`要素を基礎とするMUIコンポーネントで実装し、Space/Enterでも同じ操作ができるようにする。

## 検討した選択肢

- 往復ゲージはタイミングゲームとして分かりやすいが、Powerが自動で変化するためプレイヤーが入力を待つ時間が発生する
- Canvas全体の長押しは盤面と操作領域を共用できるが、ゲーム情報の閲覧と投射操作の領域が分かりにくくなる
- 円形の専用ボタンはモバイルとPCで同じ見た目と操作を提供しやすいため採用する

## 影響

- プレイヤーは強度だけに集中でき、Surface差を比較しやすい
- モバイルとPCで同じ入力処理を利用できる
- 投射角度を選べないため、狙い分けはPowerと既存ストーンへの衝突に限定される
- Pointer Captureまたは同等の処理により、要素外でリリースした場合も終了を検知する必要がある
- キーボード操作をMUI側に用意し、Canvasだけに入力を依存させない

## 置換

Powerを100で停止する判断は、弱い投射を狙う機会と目押しのゲーム性を増やすため、[ADR-013](./ADR-013-use-oscillating-power-gauge.md)で置き換えた。円形の投射ボタン、Pointer Events、固定投射方向の判断はADR-013でも維持する。
