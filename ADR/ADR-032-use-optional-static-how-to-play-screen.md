# ADR-032: 任意に開く静的な遊び方画面を設ける

- 状態: Accepted
- 決定日: 2026-08-23

## コンテキスト

Surface、投射距離、往復するPower Gauge、衝突、コースアウト、投射後の手動進行など、本ゲームには操作前に知っておくと理解しやすい独自ルールがある。説明をGame Screenへ常時詰め込むと、モバイルの限られた表示領域で盤面と操作が小さくなる。

一方、初回起動時にチュートリアルを強制すると、すぐ遊びたい利用者を待たせ、既読状態の保存や途中状態を追加することになる。

## 決定

- TOPに「遊び方」への入口を常に表示する
- 遊び方はGame Screenとは別の、任意に開く静的な1画面とする
- 初回起動時の強制モーダル、操作チュートリアル、既読フラグ、チュートリアル進捗を設けない
- 遊び方画面には次を掲載する
  - 円形ターゲットへストーンを滑らせ、5投の合計得点を競う目的
  - ICE、WOOD、FELTで滑りやすさが異なること
  - SHORT、MEDIUM、LONGで投射位置が異なること
  - 円形ボタンを長押しするとPowerが1から100まで往復し、離すと投射すること
  - 投射方向はターゲット中心へ固定されること
  - ストーン同士が衝突して動き、四辺から完全に出るとコースアウトになること
  - ターゲットの100、50、30、10が固定配点で、ストーン色が現在位置の得点色へ変わること
  - 1〜4投目の停止後は「次の投射へ」、5投目の停止後は「結果を見る」で進むこと
  - 各ストーンの確定得点と合計得点はResultで表示すること
  - リタイアは未完了ゲームを保存せずTOPへ戻すこと
  - タブを閉じるか再読み込みすると未完了ゲームが失われること
  - 効果音はTOPでON/OFFできること
- 「TOPへ」でTOPへ戻る
- 内容がviewportへ収まらない場合は縦スクロールを許可する

## 影響

- Game Screenへ長い説明を置かず、盤面と操作領域を優先できる
- 初回かどうかを判定する永続化データと画面状態が不要になる
- ルール変更時は遊び方の説明とゲーム仕様を同時に更新する必要がある
- 静的画面なのでPhysics Runtime、Canvas、Animation Frameを生成しない
- TOPへ戻る以外の進捗や選択状態を持たない
