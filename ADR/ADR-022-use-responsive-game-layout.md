# ADR-022: Game Screenを縦配置と横配置へレスポンシブに切り替える

- 状態: Accepted
- 決定日: 2026-08-23

## コンテキスト

本ゲームはモバイルを主対象としつつ、タブレットとPCにも対応する。Canvasの通常表示窓は縦横比`3:5`に確定しているが、すべての画面で操作領域をCanvasの下へ固定すると、横向き端末やPCでは横の余白を使えず、縦方向へ収まりにくい。一方、端末の向きを固定するとブラウザと利用環境へ不要な制約を加える。

投射ボタンの長押し中にページがスクロールすると操作を誤りやすい。ただし、ページ全体でブラウザの拡大操作を無効化するとアクセシビリティを損なう。

## 決定

- 端末の向きを固定せず、縦向きと横向きの両方をサポートする
- 狭い画面かつ縦向きでは、情報領域、Canvas、操作領域を上から順に配置する
- 横向き、または幅900 CSS px以上の画面では、Canvasを左、情報・操作領域を右に配置する
- 通常のCanvas表示窓は常に`3:5`を維持する
- Canvasは操作領域とsafe-areaを除いた利用可能な幅と高さの両方を計測し、収まる最大サイズへ縮小・拡大する
- Game Screenは動的viewportの高さへ収め、通常のページスクロールを発生させない
- 投射ボタンでは長押し中のスクロールやブラウザ既定ジェスチャーを抑止する
- ページ全体ではピンチズームなどブラウザの拡大操作を無効化しない
- TOP、設定、スコア確認、遊び方、Resultは内容が表示領域を超える場合に通常の縦スクロールを許可する
- 上下左右のsafe-area insetをレイアウトの余白へ加える

## 影響

- Game Screenは縦配置と横配置の2種類を持つが、使用するゲーム状態と操作コンポーネントは共通にする
- CanvasのCSS表示サイズは変更されても、Physics World、Camera、採点座標は変更しない
- ResizeObserverまたは同等の計測で利用可能領域を更新する必要がある
- 画面回転やウィンドウサイズ変更中もRuntimeを作り直さず、表示サイズだけを更新する必要がある
- 小さい画面ではCanvasが縮小されるため、情報と操作部品の最小サイズを確保したうえで残り領域をCanvasへ割り当てる必要がある
