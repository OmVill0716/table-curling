# ゲームルール仕様

- 状態: Accepted（MVP仕様確定）

## 1. ゲーム単位

- 1人用のブラウザゲームとする
- 1ゲームは5投とする
- ゲーム開始前にSurfaceを`ICE`、`WOOD`、`FELT`から1つ選択する
- ゲーム開始前に投射距離を`SHORT`、`MEDIUM`、`LONG`から1つ選択する
- 選択したSurfaceと投射距離は、そのゲームの5投中は変更しない
- Surface 3種類と投射距離3種類の組み合わせを、9つのハイスコアカテゴリーとする

投射距離と投射位置の数値は[`coordinates-and-rendering.md`](./coordinates-and-rendering.md)、Surfaceによる挙動の違いは[`physics.md`](./physics.md)を正本とする。

## 2. ゲーム進行

1. Game Screenを開始し、1投目を発射可能にする
2. 長押しでPowerをため、リリースで発射する
3. 盤面上にある全ストーンが停止するか盤外になるまでPhysicsを更新する
4. 投射結果を確認する`review`へ移る
5. 1〜4投目では「次の投射へ」が押された後に次のストーンを配置し、手順2へ戻る
6. 5投目では全ストーンを一度だけ採点してハイスコアを保存し、「結果を見る」を表示する
7. 「結果を見る」が押された後に、確定済み結果をResult Screenへ表示する

同時に運動しているストーンが1個でもある間と`review`中は、新しい投射を受け付けない。

1〜4投目の`review`では、固定配点付きの盤面、ストーン、`Shot N / 5`、「次の投射へ」、「リタイア」を表示し、各ストーンの現在得点と合計得点は表示しない。

5投目の`review`でも固定配点だけを表示し、各ストーンの確定得点と合計得点を伏せたまま、停止した盤面、ストーン、`Shot 5 / 5`、「結果を見る」を表示する。

画面状態、リタイア、Retryの詳細は[`screen-flow-and-input.md`](./screen-flow-and-input.md)を参照する。

## 3. 採点

採点方式と表示タイミングは[ADR-023](../../ADR/ADR-023-show-colored-score-labels-on-target.md)に従う。

5投目に関係する全ストーンの運動が終了した時点で、5個のストーンを一度だけ採点する。各ストーンの中心とターゲット中心の距離`d`を使い、ストーン半径は得点判定に含めない。

| 条件 | 得点 | 色トークン | 初期カラー |
| --- | ---: | --- | --- |
| `0 <= d && d <= 30` | 100 | `score.100` | 赤 `#D32F2F` |
| `30 < d && d <= 60` | 50 | `score.50` | オレンジ `#F57C00` |
| `60 < d && d <= 90` | 30 | `score.30` | 黄 `#FBC02D` |
| `90 < d && d <= 120` | 10 | `score.10` | 青 `#1976D2` |
| `120 < d`または盤外 | 0 | `score.0` | グレー `#757575` |

境界線上は内側の高い得点に含める。合計の最大は500点とする。

ターゲットリングとストーンは同じ得点色トークンを使う。盤上のストーンは現在の中心位置から暫定得点を毎フレーム導出し、対応する色へ動的に変える。暫定得点と色は確定得点として保存しない。

Game Screenでは固定配点以外に、各ストーンの現在得点、暫定合計、得点変化ポップアップを表示しない。プレイ中はストーン色だけを現在位置に応じて変え、ストーン上には得点数値を表示しない。

5投目の確定結果は同投目の`review`では表示せず、「結果を見る」の押下後、Resultで各ストーンの確定得点と合計得点をHTMLテキストとして初めて表示する。

得点色と固定配点の描画方法は[`coordinates-and-rendering.md`](./coordinates-and-rendering.md)を参照する。

## 4. Result Screen

- Final Scoreとして合計得点を画面内で最も大きく表示する
- Shot 1〜5を投射順に並べる
- 盤内ストーンは最終色と得点数値を表示する
- 盤外ストーンは色を得点表示に使わず、`OUT`と`0`を表示する
- 選択したSurfaceと投射距離を表示する
- 今回の記録が該当カテゴリーの上位3件へ入った場合は、`NEW HIGH SCORE`と`1st`、`2nd`、`3rd`のいずれかを表示する
- ハイスコア圏外の場合は`NEW HIGH SCORE`と順位を表示しない
- 座標値と途中得点は表示しない
- `Retry`は同じSurface・距離で新しいゲームを始める
- `TOPへ`は確認なしで選択を解除してTOPへ戻る

Resultの同点順位判定には、[`persistence.md`](./persistence.md)で定義したハイスコアの並び順をそのまま使用する。
